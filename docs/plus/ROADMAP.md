# CrossPoint Plus: roadmap

Личная прошивка для Xteink X4 Pro на основе CrossPoint Reader: читалка и библиотека CrossPoint плюс быстрые заметки
в Markdown со своей клавиатурой. Как устроен код — [ARCHITECTURE.md](ARCHITECTURE.md), набор текста —
[TYPING.md](TYPING.md).

## Принципы

1. **Просто, быстро, минималистично, в стиле системы.** Скорость и точность набора важнее богатства функций.
2. **Только X4 Pro и только сенсор** (боковые кнопки и подсветка выбора остаются для тех, кто ими пользуется).
3. **Файлы — источник истины.** Заметка — обычный `.md` в `/notes`, который читается и правится с компьютера.
4. **Сначала замер, потом оптимизация.** Скорость набора проверяется на устройстве.
5. **Минимум своего кода поверх CrossPoint**: удаляем ненужное целиком, новое пишем в отдельных модулях.

## Как ведём проект

**Задача готова**, когда сборка и тесты на компьютере проходят, автор проверил её на устройстве по короткому чек-листу,
задержка набора не выросла, решение записано в журнал, версия поднята и на карте лежит один файл прошивки
(`crosspoint-plus-x4pro.bin`).

**Релиз готов**, когда CI зелёный, опубликован релиз с заметками, OTA-обновление с прошлой версии проверено, в README
есть установка и скриншоты, а настройки по умолчанию разумны.

Версии: `<версия CrossPoint>-plus.<N>`. Работа идёт в `main`; релиз — пуш тега `*-plus.*`.

## Что дальше

1. **Публичный релиз:** README с установкой и скриншотами, заметки к релизу, тег, проверка OTA с прошлой версии.
2. **Выделение текста** (сначала обсуждение дизайна): в заметках — двойной тап или удержание, ручки границ, меню
   «копировать / вырезать / вставить»; в книгах — маркер и комментарии, их хранение и список.

### Бэклог идей
- Календарь с текущей датой (часы на устройстве есть).
- Синхронизация заметок с SilverBullet автора: файлы по HTTP (`/.fs/…`), двусторонняя по времени изменения; правила
  конфликтов обсудить отдельно.
- Новости: домашний сервер раз в день собирает RSS (например, РБК) в EPUB или Markdown, устройство скачивает по Wi‑Fi.
- Регламент обновления на новые версии CrossPoint.
