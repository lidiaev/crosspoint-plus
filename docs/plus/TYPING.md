# Набор текста на X4 Pro: конвейер, узкие места, план

Цель: набор ощущается мгновенным и точным. Markdown и заметки сейчас не рассматриваем.
Устройство: X4 Pro, контроллер панели UC8279 (LUT_VER 0x68), тач GT911, портрет 480×800, ~217 ppi.

## 1. Конвейер «палец → буква на экране»

| № | Этап | Что происходит | Сейчас | Цель | Как добиться |
|---|---|---|---|---|---|
| 1 | Касание | GT911 замечает палец, SDK отдаёт точку в основной цикл | не измерено (~10–20 мс) | ≤ 20 мс | измерить; не добавлять своих задержек |
| 2 | Распознавание клавиши | точка → клавиша, фронт касания, наложение пальцев | попадание по прямоугольнику, промахи в зазорах | 0 промахов в зазорах | ближайшая клавиша, увеличенные зоны, поправка смещения пальца |
| 3 | Очередь | клавиша → очередь → задача отрисовки | ~0 мс | — | уже без блокировок |
| 4 | Ожидание панели | буква ждёт, пока закончится предыдущая перерисовка | **до 390 мс**, в среднем ~180 | ≤ 1 перерисовка | убрать отдельный кадр «отпускания»; копить нажатия в один кадр |
| 5 | Отрисовка в буфер | перерисовка всего экрана в памяти | 17 мс | ≤ 5 мс | рисовать только строку текста и затронутые клавиши |
| 6 | Передача кадра (SPI) | весь кадр 800×600 в контроллер | 56 мс | ≤ 10 мс | передавать только изменённую полосу (окно PTL), SPI 16 → 20 МГц |
| 7 | Перерисовка панели | короткая LUT 8/16 | ~270 мс | 120–150 мс | для кадров, где только добавляются чёрные пиксели, — короткая LUT «к чёрному»; длинная «к белому» только когда есть стирание |
| 8 | Синхронизация | повторная отправка кадра как «старого» для следующего сравнения | 57 мс | ≈ 0 | авто-копирование «новое → старое» в контроллере или отправка только полосы |
| | **Итого на нажатие** | | **~390 мс кадр, ~570 мс ощущаемо** | **~150–200 мс** | |

Ключевой вывод: ощущаемая задержка — это не одна перерисовка, а очередь из них. Сначала убираем лишние кадры (этап 4), потом ускоряем сам кадр (этапы 6–8), затем саму перерисовку (этап 7).

## 2. Точность: что берём у iPhone

| Практика iOS | Зачем | Как у нас |
|---|---|---|
| Зона нажатия больше видимой клавиши, без «мёртвых» зазоров | промах между клавишами не теряется | касание относится к ближайшей клавише в своём ряду |
| Поправка на то, что палец попадает ниже и в сторону от центра | систематические промахи | калибровочный тест в лаборатории, сдвиг зон на средний промах |
| Динамический размер зон по вероятной следующей букве | меньше опечаток в словах | таблица биграмм русского (~1 КБ): вероятным буквам — шире зона, без изменения рисунка |
| Подсветка нажатой клавиши | уверенность, что нажатие засчитано | инверсия клавиши в том же кадре, что и буква; возврат — вместе со следующей буквой или в паузе, не отдельным кадром |
| Крупные клавиши, широкий пробел | меньше промахов | клавиатура на всю ширину, клавиши выше (≈ 60–64 px ≈ 7 мм), без подписей альтернативных символов |
| Понятный Shift: вид «включён/выключен», двойной тап = Caps Lock, автозаглавная в начале предложения | меньше лишних нажатий | Shift инвертирован, когда активен; автозаглавная после «. », «! », «? » и в начале текста |
| Двойной пробел → «. » | быстрый конец предложения | да |
| Удержание Backspace: повтор с ускорением, потом по словам | быстрое исправление | да |
| Цифры и знаки на отдельном слое | чистая основная раскладка | «?123» остаётся; частые знаки (, . ? !) — рядом с пробелом |
| (опционально) Ландшафт для двух больших пальцев | клавиши на ~65% шире | проверить отдельно |

## 3. Порядок экспериментов

| Шаг | Что | Ожидаемый эффект | Риск |
|---|---|---|---|
| E1 | Убрать отдельный кадр отпускания: подсветка снимается следующей буквой или после паузы ~300 мс | ощущаемая задержка −30–40% | нет |
| E2 | Замеры только по кадрам нажатий, по этапам; время касания | честные цифры для следующих шагов | нет |
| E3 | Передача только изменённой полосы (PTL окно) для обеих плоскостей + SPI 20 МГц | −90…100 мс на кадр | средний: формат окна у UC8279 |
| E4 | Убрать синхронизацию после перерисовки (авто-копирование в контроллере) | −50 мс | средний |
| E5 | LUT по содержимому кадра: «только добавление» — 8 кадров, «есть стирание» — 8/16 | −100 мс на обычной букве | следы — снимает автоочистка |
| E6 | Клавиатура v2: крупнее, без зазоров, ближайшая клавиша, Shift/Caps, двойной пробел, повтор Backspace | меньше промахов и лишних нажатий | нет |
| E7 | Тест точности: мишени на клавишах, средний промах, поправка | меньше промахов | нет |
| E8 | Биграммная подстройка зон | меньше опечаток | низкий |

Критерий готовности: фраза из 43 символов набирается в привычном темпе без единого пропуска, медианная задержка «касание → буква» ≤ 200 мс, в паузе экран чистый.

Итог: кадр ~285 мс, задержка нажатия ~300 мс, в среднем при быстром наборе ~380 мс; текст набирается без пропусков и путаницы регистра.
Остаток: изредка соседняя клавиша слева (т→и) — проверить сдвиг касаний и «Hit 30ms»; время перерисовки ограничено самой LUT (16 кадров к белому).
